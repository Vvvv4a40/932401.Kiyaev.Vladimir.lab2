# Лабораторная работа №2

Оформление личной страницы техноблога «Инжектор Гаджет» с помощью CSS.

В работе используются:

- внешний файл `style.css` как основной источник стилей;
- CSS-переменные для цветовой палитры и шрифтов;
- inline-стиль у заголовка страницы;
- внутренний блок `<style>` для полей ввода;
- позиционирование `static`, `relative` и `absolute`;
- состояния `:hover`, `:active`, `:focus` и `:visited`;
- карточки навыков в металлическом стиле с градиентом и длинной тенью.

Для просмотра достаточно открыть `index.html` в браузере.
